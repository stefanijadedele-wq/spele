# Krupis

Spēles mērķis:savākt desmit zvaigznes

## Mapju struktūra un atvēršana
- `26.html` — galvenā spēles sākumlapa
- `atteli/` — paša zīmēts PNG varonis
- `skanas/` — spēles skaņas efekts

Atvēršana: atver `26.html` interneta pārlūkā no projekta mapes.

## Dizaina izvēles un pārbaude
- Gaiši gaļš fons ar gaišu tekstu rada krupja noskaņu un skaidru kontrastu.
- Spēles laukums ir centrēts un pielāgojas arī šauram pārlūka logam.
- Pārbaudīts: attēls, skaņa un punktu skaitītājs (3 klikšķi = 3 punkti) darbojas.
- Klasesbiedra atsauksme un uzlabojums: uzlabot teksta krāsu.
